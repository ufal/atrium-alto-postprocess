# (#30 D44) The vowel-run clause is a fact about CZECH phonotactics, not about
# scanning: Czech has no triphthongs, so three vowels in a row is good evidence of
# damage -- in Czech. German and French have them natively, which is why the clause
# reached `Dauerleihe` (*aue*, permanent loan) and `FEUILLETON` (*eui*), both
# scanned perfectly correctly.
# @david-spacil, 2026-09-22: "For Czech, 3+ vowels in a row is a good rule -- Czech
# has no triphthongs. For German and French it does damage. So either split by
# language, or try 4+."

# and is the worse trade: it releases `J. Vysoean` (*Vysočan*), `POSTKRANIAINY

# giving up 3.5 lines that currently agree with `Trash` per at-risk line spared
# (stage 10b).

# everywhere INCLUDING these. Four is not "never": a German line can be scanned
# into `oueussd` as easily as a Czech one.
